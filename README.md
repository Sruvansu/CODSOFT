# CodSoft Java Programming Internship

Java programming tasks completed as part of the CodSoft internship, covering core Java fundamentals, OOP, and control flow logic.

## Tasks

### 1. Number Game
A simple number guessing game demonstrating loops, conditionals, and user input handling in Java.

### 2. Grade Calculator
Calculates a student's grade based on input marks, showcasing conditional logic and basic arithmetic operations.

### 3. ATM Interface
A console-based ATM simulation covering balance inquiry, deposit, and withdrawal operations, demonstrating menu-driven program design in Java.

Java
